## 🗺️ Missões

### ✅ Concluída: Lista GVI
Sistema que lê a lista de espera Standby GVI em PDF e mostra a posição de cada pessoa na fila do seu cargo e base.
Começou como programa de terminal, virou executável `.exe` e hoje é um site no ar com contador de acessos.

[![Site](https://img.shields.io/badge/Abrir_o_site-ff6a13?style=for-the-badge)](https://raphaalvares.pythonanywhere.com)
[![Código](https://img.shields.io/badge/Ver_o_código-0e2a47?style=for-the-badge&logo=github)](https://github.com/rafa-alvares/lista-gvi)

**Habilidades desbloqueadas:** leitura de PDF com `pypdf` · expressões regulares · Flask e templates Jinja · SQLite · deploy no PythonAnywhere · empacotamento com PyInstaller
